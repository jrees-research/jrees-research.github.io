# Personal website

Static HTML and CSS site for GitHub Pages. No build step.

## Files

- `index.html`: home page (about, research, awards, talks, experience, service, education)
- `projects.html`: projects, including the illustrative truth inference example
- `css/style.css`: styles for both pages
- `js/truth-inference-example.js`: the step-through example on the projects page
- `cv/Jess-Rees-CV.pdf`: the CV linked from both pages
- `images/photo.jpg`: your photo (if it is missing, the page shows "JR" instead)

## Changing the photo

Crop the new photo to a square, about 600 x 600 pixels, and save it as a JPEG named `photo.jpg` (lowercase). In the repository, open the `images` folder, select Add file, then Upload files, and drag in `photo.jpg`. Select Commit changes. GitHub replaces the old file.

## Updating the CV

Upload the new PDF to the `cv` folder with the same name, `Jess-Rees-CV.pdf`. GitHub replaces the old file.

## Editing text

Open the HTML file on GitHub, select the pencil icon (Edit this file), change the text, and select Commit changes. The site updates within a few minutes.
